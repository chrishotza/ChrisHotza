A later decision layer used:

CASH / FLOW

The historical idea was to separate existence detection from later action.

NodeZero, UMO, omega operator, persistence, age, decay, TTL, existence state and API made the ontology executable.

The canonical specification is dated March 22, 2026.

It uses deterministic evaluation and UMO transitions and deliberately avoids conventional token/balance/governance/PoW/PoS mechanics.

## Node Zero

Two isolated nodes receiving the same proposal produced matching existence and UID results and dissolved at the same logical step.

This was a deterministic reproducibility test, not evidence of a deployed public blockchain.

## Historical role

AEVUM is where existence, state and continuity became executable operators.
